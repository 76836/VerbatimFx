VerbatimFx Help & Features

Use this guide to find the main features of the studio.

Recording

Master Record captures active audio and MIDI inputs. Stop Recording saves the resulting recording as an asset.

Monitoring

Monitor / Waveform displays live levels for enabled audio and MIDI hardware.

Projects

Open Project Folder selects a persistent project directory for project assets and arrangements.

Timeline

Playback / Timeline lets you arrange clips, play or stop the arrangement, and export a WAV mixdown.

Devices & MIDI

Devices / Configuration controls audio inputs, MIDI inputs, aliases, MIDI passthrough, and available SoundFonts.
